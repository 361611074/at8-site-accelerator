## 一、产品形态

### Q1. Pro 版是独立插件，还是同一插件的解锁模式？

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| **独立插件** | Free 版体积小、代码简单；用户可只装一个 | 两份 `includes/` 基础层会重复；同时装两个会冲突 |
| **同插件解锁** | 代码只有一份；升级路径平滑 | Free 版会带上 Pro 的代码（体积与"隐藏功能"的观感问题） |
| **同插件 + 独立 Pro 包** | Free 保持干净，Pro 包覆盖基础层 | 打包与版本管理复杂 |

**影响的技术决策**：目录结构、`Plugin::boot()` 的服务登记方式、
两版共装时的检测逻辑。

**建议**：独立插件 + 复用 Free 的 `includes/`（Pro 包内自带一份基础层副本，
用常量检测避免重复加载）。理由：Free 版用户是绝大多数，不应该为少数付费用户
背上额外体积。

### Q2. 定价与授权粒度？

- 单站点 / 3 站点 / 不限站点？
- 年付 / 终身？
- 是否提供免费试用期？
- 是否区分"个人"与"商业"用途？

**影响的技术决策**：授权校验的调用频率、是否允许离线激活、
域名变更的迁移流程。

### Q3. 目标市场优先级？

- WordPress.org 免费版分发 + 自建站卖 Pro？
- 还是先进国内的应用市场 / 建站服务商渠道？

**影响的技术决策**：更新服务器地址、支付渠道、是否需要备案与合规材料。

## 二、支付

### Q4. 支付渠道

| 渠道 | 适用 | 需要准备 |
| --- | --- | --- |
| Stripe | 海外用户 | 主体资质、税务信息 |
| 支付宝 / 微信支付 | 国内用户 | 企业主体、经营类目 |
| PayPal | 海外补充 | — |
| 第三方（Gumroad / Lemon Squeezy） | 快速起步，代为处理税务 | 平台抽成 |

**影响的技术决策**：支付回调的验签方式、订单状态机、退款流程。

> 本项目已有一套成熟的支付宝/汇付支付集成经验可复用，
> 但**必须先确定是"卖许可证"还是"卖订阅"**——两者的状态机完全不同。

### Q5. 订阅还是买断？

- 买断：实现简单，无续费逻辑，但收入一次性；
- 订阅：需要处理续费、宽限期、到期降级、退款。

**影响的技术决策**：授权校验的周期、离线宽限期长度、到期后的行为
（是停止 Pro 功能还是只停更新？）。

### Q6. 退款与争议处理策略？

**影响的技术决策**：授权吊销接口、自动退款流程。

## 三、授权与更新

### Q7. 授权校验强度？

| 强度 | 实现 | 代价 |
| --- | --- | --- |
| 仅激活时校验 | 简单，体验好 | 破解容易 |
| 定期心跳（如每 7 天） | 中等 | 需要处理网络不可用 |
| 每次请求校验 | 不可行 | 会拖慢站点，且用户会强烈反对 |

**建议**：激活时校验 + 定期心跳 + 长期离线宽限（30 天）。
付费插件的用户是客户，不是嫌疑人——过度的校验设计伤害的是付费用户的体验，
而破解者本来就能绕过。

### Q8. 本地/测试环境如何免授权？

必须提供，否则开发者无法在 staging 站点上使用。
常见做法：识别 `localhost` / `.test` / `.local` / `WP_ENVIRONMENT_TYPE=local` 自动放行。

### Q9. 更新分发渠道？

- 自建更新服务器（`pre_set_site_transient_update_plugins` 钩子）；
- 还是用第三方（Freemius / EDD Software Licensing）？

**影响的技术决策**：更新包签名与校验、回滚机制。

### Q10. 是否上架 WordPress.org？

上架有两条硬性要求与本项目现状冲突，需要决策：

1. **不允许"试用版"式功能锁**。Free 版必须功能完整——本项目的 Free 版
   （见 `FREE_PRO_MATRIX.md`）满足这一条。
2. **不允许插件主动请求外部服务器做授权校验**（免费版）。
   Pro 版不能上架 WordPress.org，只能自建渠道分发。

## 四、法务与合规

### Q11. 是否需要用户协议与隐私政策？

若收集任何数据（哪怕是站点 URL 用于授权校验），就需要。
**当前 Free 版不收集任何数据**，这是明确的产品承诺，写进了 `readme.txt`。
Pro 版的授权校验会改变这一点，必须在协议中说明。

### Q12. 商标与品牌？

- "AT8" 是否已注册？
- 白标功能是否允许用户移除品牌？（`FREE_PRO_MATRIX.md` 里列为 Pro 功能）

### Q13. 是否开源？

- 当前 `LICENSE` 为 GPL-2.0-or-later（WordPress 生态的标准选择）。
- 如果 Pro 版也要用 GPL，任何人都可以合法再分发 Pro 代码。
- 常见做法：Free 版 GPL，Pro 版用商业许可（技术上不受 GPL 约束，
  因为它是独立作品而非 Free 版的衍生）。

**这是一个必须先定的问题**：它决定了 Pro 代码能否复用 Free 的 `includes/`。
若 Pro 是 Free 的衍生作品，GPL 会传染，商业许可在法理上站不住。

## 五、当前可以确定的事项

以下几条不依赖上面的决策，现在就可以写进任何版本的文档：

1. **Free 版永久免费、功能完整、无时间限制、无用量限制、无广告**。
2. **Free 版不收集任何用户数据**，不做任何外部请求（除 WordPress 自身的更新检查）。
3. **Free 版不上"功能锁"**：不会出现"升级 Pro 解锁"的灰化按钮。
4. **Pro 版不通过关闭 Free 已有功能来制造差异**。
